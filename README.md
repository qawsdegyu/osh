# عُش للعطور (OSH Perfume) 🌿✨

موقع متجر "عُش للعطور" - تجربة تسوق إلكترونية لعطور فاخرة وأصيلة بتصميم عصري وأنيق.

## 🌟 المميزات
- تصميم متجاوب يعمل بكفاءة على مختلف الشاشات والأجهزة الذكية.
- استعراض تشكيلات العطور النسائية والرجالية والباقات الخاصة.
- واجهة مستخدم متناسقة وأنيقة باللغة العربية مع خطوط وتنسيقات عصرية.
- سلة مشتريات وتجربة طلب سهلة وسلسة.

## 🚀 المعاينة والتشغيل
يمكن فتح وتشغيل الموقع مباشرة عبر فتح ملف `index.html` في أي متصفح ويب حديث.
